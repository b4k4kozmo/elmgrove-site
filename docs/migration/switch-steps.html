elmgrove.games → GitHub Pages

Switch-over steps

About 15 minutes. You need your Namecheap login and GitHub open in a browser (use "desktop site" on a phone: the GitHub app has no Pages settings). Do the steps in order. Nothing here touches the hosting, so the old site stays up as a fallback.

0 / 4
1

GitHub

Claim the domain on GitHub

  1. Profile picture → Settings → Pages (left menu, under "Code, planning…").
  2. Add a domain → type elmgrove.games → Add.
  3. GitHub shows a TXT record. Its host is _github-pages-challenge-b4k4kozmo. Copy its value and keep the tab open: you paste it in step 3.
2

Namecheap · Domain List

Switch the nameservers

  1. Domain List → elmgrove.games → Manage.
  2. Nameservers: change Namecheap Web Hosting DNS to Namecheap BasicDNS → tick ✓ to save.

Go straight on to steps 3 and 4. Until they're done the site and mail have no address.

3

Namecheap · Advanced DNS → Host Records

Point the site at GitHub

  1. Delete Namecheap's parking records if they're there: a CNAME www → parkingpage.namecheap.com and a URL Redirect @.
  2. Add New Record for each row. TTL: Automatic.
TypeHostValue
  1. Back in the GitHub tab from step 1, press Verify. If it fails, wait ten minutes and try again.
4

Namecheap · Advanced DNS → Mail Settings

Turn on email forwarding

  1. Mail Settings → choose Email Forwarding → save. Namecheap adds the mail records itself; don't add them by hand.
  2. Add one forwarder per alias. They're under Domain tab → Redirect Email, or listed under Mail Settings. Type each person's own inbox as the destination.

Then

Tell Claude "DNS is switched"

🔒

A week later, once all is well

Lock things down

The old mailboxes and files aren't needed: the site is saved in the repo, and nobody used the mail.

  • cPanel → Email Accounts: delete every mailbox.
  • cPanel → File Manager → public_html: delete the site files (the copy is in the repo).
  • cPanel → FTP Accounts: delete any extra accounts.
  • Namecheap → Profile → Security: turn on two-factor sign-in if it isn't on, and change the password if it's old or shared.
  • Domain List → elmgrove.games: Domain Lock ON, Domain Privacy ON, the domain's auto-renew ON. Check the expiry date.
  • Hosting: turn its auto-renew OFF. Cancel it when you're ready; cancelling wipes the account, which also cleans it up.

Undo at any point before cancelling: set the nameservers back to Namecheap Web Hosting DNS and the old site and mail come back.
